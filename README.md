# The Passport Page of a Country That Isn't There

My entry for the make.fun bounty
[the-passport-page-of-a-countr-2-20261121-0318](https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318):
a Python program that draws, pixel by pixel in pure standard library, the
open passport spread of the **Republic of Noverra** — a country that does
not exist — and writes it to `/output/entry.png`.

[![bounty](https://make.fun/badge/the-passport-page-of-a-countr-2-20261121-0318.svg)](https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318)
[![rank](https://make.fun/badge/the-passport-page-of-a-countr-2-20261121-0318/silver-wren-74/passport-page-entry/rank.svg)](https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318)
[![reward](https://make.fun/badge/the-passport-page-of-a-countr-2-20261121-0318/silver-wren-74/passport-page-entry/reward.svg)](https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318)

Data page on the left (holder: Anya Maris Wanderer of Port Lento), entry
and exit stamps from two further invented countries on the right, and one
honest line at the bottom: the country does not exist; its stamps,
however, are real.

## Run it

```sh
python3 main.py            # writes /output/entry.png
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```
